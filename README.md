# 🐍 霓虹贪吃蛇 (Cyberpunk Neon Snake)

一款兼具赛博朋克霓虹视觉、纯原生 Web Audio 合成音效、多重玩法与流畅物理手感的网页版贪吃蛇。

## ✨ 特性亮点

- 🎨 **赛博朋克炫彩画质**：深空蓝黑背景、霓虹辉光网格、灵动蛇眼视线追踪、呼吸感食物动画与粒子爆发特效。
- 🎵 **纯原生离线音效**：基于 Web Audio API 动态合成的街机音效（吞食、三和弦金苹果、连击电音、撞毁音效），无需下载任何音频文件，毫秒级响应。
- ⚡ **连击 (Combo) 系统**：短时间内连续进食可触发连击加成（最高 3.0x 分数加成），尽享街机爽快刷分！
- 🍏 **丰富道具**：
  - **普通霓虹果 (🍎)**：+10 分，增长身躯。
  - **金色星星果 (⭐)**：随机限时刷出，超高 +50 分与连击加成。
  - **极寒冰晶果 (❄️)**：提供缓速减速效果，化解险境。
- 🕹️ **双重模式 & 四档速度**：
  - **经典模式**：撞墙即死，考验精细微操。
  - **无尽穿墙**：边缘穿越，畅享超长蛇身生存快感。
  - **速度档位**：休闲 (125ms) / 标准 (90ms) / 极速 (65ms) / 狂暴 (45ms)。
- 📱 **多端全适配**：支持键盘（WASD / 方向键）、触屏滑动（Swipe）以及屏幕虚拟方向轮盘。

## 🎮 操作指南

| 按键 / 操作 | 功能 |
| :--- | :--- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> 或 <kbd>↑</kbd> <kbd>←</kbd> <kbd>↓</kbd> <kbd>→</kbd> | 控制蛇移动方向 |
| <kbd>空格键 (Space)</kbd> | 开始游戏 / 暂停 / 继续 |
| <kbd>R</kbd> | 重新开始本局 |
| <kbd>M</kbd> | 静音 / 开启音效 |
| 屏幕方向按键 / 滑动手势 | 触屏或鼠标简易控制 |

## 🚀 启动方式

- **方式一（直接打开）**：双击直接在任意浏览器打开 `index.html`。
- **方式二（本地服务器）**：在终端运行 `python3 -m http.server 8080`，然后在浏览器访问 `http://localhost:8080`。
